# 🍎 Fridge - Gerenciamento de Frutas

API desenvolvida em Java com Spring Boot para o gerenciamento de frutas e alimentos armazenados na geladeira.

## 📋 O que o projeto faz?

O **Fridge** funciona como um sistema de controle de estoque doméstico (CRUD completo). Ele permite organizar os alimentos disponíveis através das seguintes funcionalidades:

* **Cadastrar frutas:** Adiciona novas frutas ao sistema informando seus detalhes (como nome, quantidade e validade).
* **Listar frutas:** Consulta todas as frutas armazenadas ou busca por um item específico através do seu ID.
* **Atualizar dados:** Modifica informações de uma fruta já cadastrada, como alterar a quantidade disponível.
* **Remover itens:** Exclui frutas que já foram consumidas ou descartadas.

O sistema utiliza um banco de dados em memória (H2) para armazenar os registros de forma rápida durante a execução.
